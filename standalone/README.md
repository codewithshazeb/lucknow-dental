# Lucknow Dental And Implant Center (लखनऊ डेंटल केयर)
Website Source Code - Pure HTML, CSS & JavaScript

## How to Run:
1. Extract all files into a folder.
2. Double click 'index.html' to open in any web browser (Chrome, Edge, Firefox, Safari).
3. No server or Node.js required!

## Deployment:
You can directly upload 'index.html', 'style.css', and 'script.js' to:
- cPanel / Shared Hosting (public_html)
- Hostinger, GoDaddy, Bluehost, Namecheap
- GitHub Pages
- Netlify or Vercel (static)
